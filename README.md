# bloc3_exo_login

Règles de gestion : 
* Le login est composé du nom de famille et de la première lettre du prénom séparés par un point.
* Les caractères autorisés sont les minuscules de a à z, é, è et ç.
* Le nom de famille est limité à 20 caractères, et le prénom à 3 caractères.

Jeux de test :
* Chaigneau Mathis => chaigneau.m
* Maçon Lucas => maçon.l
* Laforêt-Dubois Marine => laforetdubois.m
